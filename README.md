# Hamid Store — মোঃ হামিদুল হক নাবিল

একটি সম্পূর্ণ অনলাইন বইয়ের দোকান ও অ্যাডমিন প্যানেল, যেখানে গ্রাহকরা বই অর্ডার করতে পারেন এবং অ্যাডমিন সবকিছু নিয়ন্ত্রণ করতে পারেন। বাংলা ভাষায় সম্পূর্ণ ইন্টারফেস, Hind Siliguri ফন্ট, এবং ৬টি থিম।

## বৈশিষ্ট্য

### গ্রাহক সাইট
- **হোম পেইজ**: ফিচারড, বেস্টসেলার ও নতুন বইয়ের ক্যারোসেল
- **বইয়ের তালিকা**: ক্যাটাগরি ও ট্যাগ অনুযায়ী ফিল্টার
- **বইয়ের বিস্তারিত**: 3D বুক মকআপ, প্রিভিউ পেজ, প্রিন্টেড ও ই-বুক অপশন
- **কার্ট**: একসাথে প্রিন্টেড ও ই-বুক কার্টে যোগ
- **চেকআউট**: bKash, Nagad, ক্যাশ অন ডেলিভারি
- **অর্ডার ট্র্যাকিং**: অর্ডারের বর্তমান অবস্থা দেখা
- **অ্যাকাউন্ট**: অর্ডার হিস্ট্রি, ঠিকানা ব্যবস্থাপনা
- **গ্রাহক লগইন**: ফোন নম্বর বা ইমেইল দিয়ে
- **পাসওয়ার্ড রিসেট**: গ্রাহক ও অ্যাডমিন উভয়ের জন্য

### অ্যাডমিন প্যানেল
- **ড্যাশবোর্ড**: বিক্রি, অর্ডার, স্টক সারাংশ
- **বই ব্যবস্থাপনা**: বই যোগ/সম্পাদনা, কভার আপলোড, প্রিন্টেড ও ই-বুক দাম
- **অর্ডার ব্যবস্থাপনা**:
  - অর্ডারের অবস্থা আপডেট (received → confirmed → processing → ready → completed)
  - পেমেন্ট যাচাই
  - **ম্যানুয়াল অর্ডার**: ফোনে নেওয়া অর্ডার যোগ
  - **গিফট অর্ডার**: গিফট টগল চালু করলে ০ টাকা, ডাটাবেজে ০, UI-তে "Gifted"
  - **কাস্টম দাম**: প্রতিটি বইয়ের দাম অ্যাডমিন নির্ধারণ করতে পারে (যেমন ১৫০/- এর বইয়ে ১০০০/-)
- **গ্রাহক ব্যবস্থাপনা**: গ্রাহকের তালিকা ও অর্ডার হিস্ট্রি
- **স্টক ব্যবস্থাপনা**: প্রতিটি বইয়ের স্টক
- **হিসাব (Ledger)**: প্রতিটি অর্ডারের পেমেন্ট হিসাব
- **স্টোর সেটিংস**: স্টোরের নাম, লোগো, লেখকের প্রোফাইল
- **অ্যাপিয়ারেন্স**: ৬টি থিম (সবুজ, নীল, বেগুনি, গোলাপি, সোনালি, টিল)
- **পেমেন্ট সেটিংস**: bKash, Nagad, COD
- **ডেলিভারি সেটিংস**: ঢাকা, ঢাকার বাইরে, পিকআপ চার্জ
- **টেলিগ্রাম সেটিংস**: অর্ডার নোটিফিকেশন
- **ইমেইল SMTP সেটিংস**: অর্ডারের প্রতিটি ধাপে গ্রাহককে ইমেইল

### আলাদা অ্যাডমিন ও গ্রাহক সেশন
- অ্যাডমিন ও গ্রাহক লগইন সম্পূর্ণ আলাদা — একই ব্রাউজারে একসাথে উভয় লগইন থাকতে পারে
- দুটি আলাদা Supabase ক্লায়েন্ট, আলাদা স্টোরেজ কী-সহ

## প্রযুক্তি

- **Frontend**: React 19, TypeScript, Vite
- **UI**: Shadcn UI, Tailwind CSS v4, Lucide icons
- **Font**: Hind Siliguri (Google Fonts)
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- **Database**: PostgreSQL with Row Level Security (RLS)

## ইমেইল সেটআপ

অ্যাডমিন প্যানেলে `সেটিংস > ইমেইল SMTP` থেকে SMTP কনফিগার করুন:
- SMTP হোস্ট (যেমন smtp.gmail.com)
- SMTP পোর্ট (587 বা 465)
- SMTP ইউজারনেম ও পাসওয়ার্ড
- প্রেরকের নাম ও ইমেইল

চালু করলে অর্ডারের প্রতিটি ধাপে (received, confirmed, processing, ready, completed) গ্রাহককে ইমেইল পাঠানো হবে।

## ডাটাবেস স্কিমা

### মূল টেবিল
- `books` — বইয়ের তথ্য
- `customers` — গ্রাহকের প্রোফাইল
- `orders` — অর্ডার (is_gift কলাম গিফট অর্ডার চিহ্নিত করে)
- `order_items` — অর্ডারের আইটেম (custom_price কলাম কাস্টম দাম)
- `cart_items` — কার্ট
- `addresses` — ঠিকানা
- `ledger_entries` — হিসাব
- `site_settings` — স্টোর সেটিংস (active_theme কলাম থিম সংরক্ষণ)
- `delivery_settings` — ডেলিভারি চার্জ
- `payment_settings` — পেমেন্ট সেটিংস
- `email_settings` — SMTP কনফিগারেশন
- `author_profiles` — লেখকের প্রোফাইল

### সিকিউরিটি
- সব টেবিলে Row Level Security (RLS) চালু
- গ্রাহক শুধু নিজের ডাটা দেখতে/সম্পাদনা করতে পারে
- অ্যাডমিন সব ডাটা নিয়ন্ত্রণ করতে পারে (is_admin() ফাংশন দিয়ে)

## গিফট অর্ডার

ম্যানুয়াল অর্ডার যোগ করার সময় "গিফট অর্ডার" টগল চালু করলে:
- সব আইটেমের দাম ০ টাকা হয়ে যায়
- ডেলিভারি চার্জ ০
- সর্বমোট "Gifted" হিসেবে দেখায়
- ডাটাবেজে total = 0, is_gift = true
- পেমেন্ট স্ট্যাটাস স্বয়ংক্রিয়ভাবে "verified"

## কাস্টম দাম

ম্যানুয়াল অর্ডারে প্রতিটি বইয়ের জন্য আলাদা দাম সেট করা যায়। খালি রাখলে বইয়ের ডিফল্ট দাম ব্যবহার হয়। এতে গ্রাহক যেকোনো পরিমাণ টাকা দিতে পারে (যেমন ১৫০/- এর বইয়ে ১০০০/-)।
